# Havensais Security

Навчальний лендінг про основи цифрової кібергігієни. Сторінка пояснює базові правила захисту облікових записів і персональних даних в інтернеті.

## Про проєкт

Сайт містить:

- головну hero-секцію з коротким описом теми;
- кнопку плавної прокрутки до правил безпеки;
- три картки з порадами щодо кібергігієни;
- навігацію між секціями сторінки;
- адаптивний підвал із навчальною інформацією.

## Особливості

- семантична HTML5-структура з `header`, `nav`, `main`, `section` і `footer`;
- Flexbox для вирівнювання елементів;
- темна кольорова схема в стилі cybersecurity;
- плавні hover-ефекти для логотипа, навігації та кнопки;
- плавна прокрутка між секціями;
- адаптивне розташування елементів на вузьких екранах.

## Технології

- HTML5
- CSS3
- Flexbox
- CSS transitions

## Запуск

Відкрийте файл `index.html` у браузері або запустіть папку через локальний Live Server.
